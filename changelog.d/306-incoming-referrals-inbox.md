Phase 3: target doctors can see referrals aimed at them through `GET /referrals/incoming` ([issue #306](https://github.com/DocForum/docforum-core/issues/306)). The endpoint is scoped to the caller's own `DoctorProfile`, defaults to `pending`/`accepted`, accepts a `status` filter for terminal referrals, and uses `(createdAt, id)` keyset pagination over the existing `targetDoctorId` index. Snapshot notes are returned decrypted when encryption lands, and every returned row writes a PHI access log naming the target doctor as viewer. Reassignment changes only `targetDoctorId`, so moved referrals leave the old target's inbox and enter the new one. No schema changes.
