| `GET /availability/closures` | none | — | The closure calendar for clients. Returns `{ closures: [{ id, version, scope, facilityProfileId, startDate, endDate, timeZone, reason, createdAt, updatedAt }] }`; `startDate`/`endDate` are inclusive `YYYY-MM-DD` days read in `timeZone`. Optional `?from=&to=` (calendar dates) and `?scope=platform\|facility`; defaults to closures that have not ended yet. Public on purpose — a closure carries no patient data. |
| `GET /availability/admin/closures` | admin | — | Same shape and filters; returns every closure unless `from`/`to` are given. |
| `POST /availability/admin/closures` | admin | `{ scope: 'platform'\|'facility', facilityProfileId?, startDate, endDate, timeZone?, reason }` | Creates the closure and applies it immediately. `201` returns `{ closure, openSlotsRemoved, affectedBookings: [{ appointmentId, doctorProfileId, startTime }], affectedBookingCount }`. Booked appointments in the range are **reported for manual handling, never cancelled**. `scope: 'facility'` requires `facilityProfileId` (`400 CLOSURE_FACILITY_REQUIRED`); `scope: 'platform'` refuses one (`400 CLOSURE_SCOPE_CONFLICT`); unknown facility `404 FACILITY_NOT_FOUND`; inverted range `400 INVALID_DATE_RANGE`; over the 365-day horizon `400 DATE_RANGE_TOO_LARGE`; bad IANA zone `400 INVALID_TIME_ZONE`. Writes a `closure.created` audit event in the same transaction. |
| `GET /availability/admin/closures/:closureId` | admin | — | Single closure. Emits strong `ETag` carrying its `version` — the `If-Match` value for `PATCH`. `404 CLOSURE_NOT_FOUND`. |
| `PATCH /availability/admin/closures/:closureId` | admin | `{ startDate?, endDate?, timeZone?, reason? }` (at least one) + `If-Match` | One conditional `UPDATE ... WHERE id = ? AND version = ?` that increments `version` (`428` without `If-Match`, `400` weak/list validator, `412` stale). The calendar is re-applied for the resulting range, so extending a closure over more days removes those days' open slots and reports their bookings in the same response shape as `POST`. Writes a `closure.updated` audit event. |
| `DELETE /availability/admin/closures/:closureId` | admin | — | Removes the closure (`204`). Slots it already removed are **not** restored — the doctor regenerates availability. Writes a `closure.deleted` audit event. `404 CLOSURE_NOT_FOUND`. |
